# 🌿 PlantSteller - Minimal Version

PlantSteller is a modern plant e-commerce website designed to help users discover, explore, and purchase plants through a clean and user-friendly experience.

## Features

* Plant Catalog
* Product Search
* Wishlist
* Community Reviews
* Corporate Gifting
* AI Plant Assistant
* Responsive Design

## Tech Stack

* React.js
* Vite
* Tailwind CSS
